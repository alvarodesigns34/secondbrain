# Bandeja de ideas

Sitio para que Álvaro (o cualquiera) apunte ideas sueltas, inspiración, referencias o ocurrencias que todavía no están maduras para ser una decisión de visión o una tarea concreta. No hace falta que estén bien redactadas ni justificadas.

Claude revisa esta lista periódicamente y, para cada entrada, decide una de estas acciones: incorporarla a [`VISION.md`](VISION.md), convertirla en una tarea (issue) cuando llegue el momento, guardarla como investigación en `docs/04-research/`, o descartarla explicando por qué. Cuando una idea se procesa, se marca como tal y no se borra (queda como registro histórico).

Formato sugerido por entrada:

```
### 2026-09-06 — Título corto de la idea
Descripción libre.
**Estado:** sin procesar / incorporada a VISION.md / convertida en tarea (#N) / descartada (razón)
```
