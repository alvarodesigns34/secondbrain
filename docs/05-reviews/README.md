# Revisiones de Antigravity (fuera de una PR concreta)

La mayoría de las revisiones de Antigravity viven directamente en la Pull Request que revisan (ver [`docs/03-process/WORKFLOW.md`](../03-process/WORKFLOW.md)). Esta carpeta es para **auditorías que no están ligadas a una PR concreta**: revisiones de arquitectura general, del propio proceso de colaboración, o de un conjunto de decisiones acumuladas.

## Convención

- Un archivo por auditoría: `AAAA-MM-DD-tema.md`.
- Misma estructura fija que una revisión de PR: **Veredicto**, **Riesgos**, **Debe corregirse**, **Sugerencias opcionales**, **Preguntas para Claude**, **Qué está bien hecho**.
- Tras publicarla, Antigravity abre (o pide que se abra) un issue con `Turno: Claude` enlazando al archivo, para que quede en el flujo de trabajo normal y no se pierda como documento aislado.
