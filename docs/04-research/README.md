# Investigación

Espacio para investigación libre de cualquier agente: comparativas de librerías/tecnologías, prototipos de descarte, notas sobre cómo resuelven este problema otras herramientas, exploración de un problema antes de comprometerse a una decisión de arquitectura.

## Convención

- Un archivo por tema: `AAAA-MM-DD-tema-corto.md`.
- Al principio del archivo, indicar quién lo escribió y con qué pregunta en mente (normalmente, una de las preguntas abiertas de [`VISION.md`](../00-vision/VISION.md) o [`ARCHITECTURE.md`](../02-architecture/ARCHITECTURE.md)).
- La investigación no es vinculante por sí sola: si sus conclusiones deben convertirse en una decisión, eso se documenta aparte como ADR en `docs/02-architecture/decisions/`, referenciando el archivo de investigación correspondiente.
